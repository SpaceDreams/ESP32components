# Component Library
This library is meant to be used as a library for your own code; or as a framework to build your own components.

## Tested and Working Libs:
- [x] initADC
- [x] I2S_pcm
- [ ] initI2S_pdm -- No board to test with
- [x] SDcard -- tested on the CRB Surveillance Board and the SparkThingsC Board
- [x] ADC2sd -- tested on the SparkThingsC Board
- [x] EdgeImpulse -- It's only a skeleton directory, so it works as long as the Edge Impulse model folders are inserted.
