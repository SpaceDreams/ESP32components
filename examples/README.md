# Examples Library
This library is meant to be used as a library for your own code; or as a framework to build your own components.

## Tested and Working Libs:
- [x] I2Srecording
- [x] EdgeImpulse_I2S_SD_16bit -- using the tflite model it matches very closely with edge impulse results.
- [ ] EdgeImpulse_I2S_SD -- Runs but doesn't match Edge Impulse
- [ ] EdgeImpulse_continuous_I2S -- Runs but doesn't match Edge Impulse
- [ ] EdgeImpulse_I2S_SD_24bitCompressed -- runs, matches edge impulse but terrible at classifying and the compression algorithm is slow, so it skips while sampling.
- [ ] ESP_DL -- Runs but the classification never changes.
